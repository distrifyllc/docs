---
title: 'Get Organization Profile'
description: 'Retrieve the profile of the organization scoped by x-org-id'
---

## Endpoint

```
GET /api/organizations/v1/profile
```

## Headers

| Name | Required | Description |
|---|---|---|
| `Authorization` | yes | `Bearer <token>` issued by the auth service |
| `x-org-id` | yes | UUID of the organization to scope the request to |
| `Accept-Language` | no | `en` or `es` for localized error messages |

## Errors

| Status | When |
|---|---|
| `401` | Missing or invalid `Authorization` or `x-org-id` |
| `404` | Organization does not exist or has been deleted |
