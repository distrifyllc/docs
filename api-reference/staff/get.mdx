---
title: 'Get Staff'
description: 'Retrieve a single staff member by ID'
---

## Endpoint

```
GET /api/organizations/v1/staff/{id}
```

## Path parameters

| Name | Type | Description |
|---|---|---|
| `id` | uuid | Staff member ID |

## Headers

`Authorization: Bearer <token>`, `x-org-id` — required.

## Errors

| Status | When |
|---|---|
| `404` | Staff member not found in this organization |

## Related

- `GET /api/organizations/v1/staff/profile` — returns the staff record for the authenticated user.
