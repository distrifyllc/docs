---
title: 'Delete Staff'
description: 'Soft-delete a staff member by ID'
---

## Endpoint

```
DELETE /api/organizations/v1/staff/{id}
```

## Path parameters

| Name | Type | Description |
|---|---|---|
| `id` | uuid | Staff member ID |

## Headers

`Authorization: Bearer <token>`, `x-org-id`.

## Response — `204 No Content`

The staff record is soft-deleted (`deletedAt` is set). It will no longer appear in list/get queries.

## Errors

| Status | When |
|---|---|
| `404` | Staff member not found in this organization |
