---
title: 'Toggle Staff Active'
description: 'Enable or disable a staff member without deleting them'
---

## Endpoint

```
PATCH /api/organizations/v1/staff/{id}/toggle-active
```

## Path parameters

| Name | Type | Description |
|---|---|---|
| `id` | uuid | Staff member ID |

## Headers

`Authorization: Bearer <token>`, `x-org-id`, `Content-Type: application/json`.

## Request body

| Field | Type | Required |
|---|---|---|
| `isActive` | boolean | yes |

```json
{ "isActive": false }
```

## Response — `200 OK`

Returns the updated `StaffDTO` with the new `isActive` value.

## Errors

| Status | When |
|---|---|
| `400` | `isActive` missing |
| `404` | Staff member not found in this organization |
