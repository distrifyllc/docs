---
title: 'List Staff'
description: 'Paginated list of staff members for the scoped organization'
---

## Endpoint

```
GET /api/organizations/v1/staff
```

## Headers

| Name | Required |
|---|---|
| `Authorization: Bearer <token>` | yes |
| `x-org-id` | yes |

## Query parameters

| Name | Type | Default | Description |
|---|---|---|---|
| `page` | int | `1` | Page number (1-indexed) |
| `pageSize` | int | `20` | Items per page (max 100) |
